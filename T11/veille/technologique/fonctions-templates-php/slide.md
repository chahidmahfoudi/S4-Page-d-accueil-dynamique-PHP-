## Synthèse de ma veille technologique

- Définition en une phrase : La modularité consiste à diviser une application en plusieurs fichiers et fonctions réutilisables afin d'organiser le code et éviter les répétitions.

- Problème résolu pour le projet : Éviter la duplication du code dans les différentes pages du Blog, faciliter les modifications et réduire les risques d'erreurs.

- Mes 3 mots-clés : Inclusion (`require_once`) — Fonctions réutilisables — Principe DRY (Don't Repeat Yourself).
